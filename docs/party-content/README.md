| 대분류 | 규칙 |
|---|---|
| SONG | 제목만 맞히면 정답. 가수 불필요. `song_answer` 변형(영→한 음역 등) 인정 |
| SCREEN | 작품명. 시즌·부제 없어도 인정("범죄도시", "어벤져스"). 줄임말은 인정답안 열 |
| ANIME | 한국판·일본판 제목 모두 인정("카드캡터 체리"="사쿠라"). 극장판·TV판 구분 안 함 |
| GAME | 중분류가 게임명이면 게임명은 이미 보이므로 **캐릭터·유닛·맵 이름**을 말해야 정답. 중분류가 **게임 맞히기**면 소리만 듣고 **게임 이름**을 말하면 정답. 줄임말(헤네·다템·쿠크·동숲·테런·크아·던파) 인정 |
| PERSON | 예명·본명·별명 모두 인정(GD=권지용, 페이커=이상혁) |
| QUIZ | 초성은 정확한 단어. 속담은 뜻이 같으면 어미 차이 인정 |
| SOUND | 프로그램명·브랜드명. 줄임말 인정(나혼산·그알). CM송은 제품명이든 회사명이든 인정(초코파이=오리온 초코파이) |

## 저작권 메모 (계획서 §3·§10)
- 사진·캡처는 정당하게 접근한 화면에서 뜨고 노트북 폴더에만 둔다. **이 폴더에 이미지를 넣지 않는다.**
- 클립은 공식 채널 우선. 팬 업로드는 삭제가 잦으니 등록 후 재검증.
- 게임 대사는 검색용 식별 문구만 적었다. 화면엔 대사를 띄우지 않고 클립을 듣는다. **대사 원문 출처**(2026-09-29): 캐릭터 맞히기 41개 전부 `비고` 에 나무위키 `캐릭터/대사` 페이지 링크. 자동 추출은 신뢰도가 낮아(라인하르트·디바 결과가 게임과 다름) **MC 가 페이지를 열어 한 줄씩 확인**한다. 확인된 것은 `보조` 에 원문 인용. 이름이 들리는 대사(티모 픽·겐지 픽·SCV 첫 대사·라인하르트 픽·디바 자기소개·로아 NPC 가 군단장 이름 부르는 구간)는 피한다.
