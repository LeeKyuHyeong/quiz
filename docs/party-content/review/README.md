# 클립 듣기 검수 도구 (2026-10-12)

`sound.tsv`·`anime.tsv`·`game.tsv` 의 AUDIO 문제 122행에 YouTube 후보(행당 2개, 전부 임베드 가능 확인)를 붙여 두었다.
사람이 듣고 영상·시작초·길이를 정하면, 결과를 Claude 에게 붙여 TSV 에 채운다. **TSV 의 URL 칸은 듣고 확인한 것만 채운다**(README "YouTube URL — 검증 없이 적지 않는다").

## 여는 법
YouTube 플레이어는 `file://` 에서 안 돌아서 로컬 서버로 연다(저장소 루트에서):
```bash
python -m http.server 8090 --bind 127.0.0.1 --directory docs/party-content/review
```
브라우저로 `http://localhost:8090` (창을 닫으려면 그 터미널에서 Ctrl+C).
**일반 Chrome 으로 연다** — Claude 데스크톱 앱의 내장 브라우저에서는 YouTube 임베드가 "플레이어 구성 오류 153"으로 막혀 플레이어의 onReady 가 안 오고 ▶ 를 눌러도 영상이 안 실린다(10-12 확인, 페이지 코드 문제 아님). 검수는 **데스크탑에서** 이어간다(행사 노트북은 사양이 낮아 검수에 안 씀) — 결과가 그 브라우저에만 저장되니 한 PC 에서 끝낸다(10-12 결정).

## 쓰는 법
1. 위에서 대분류(SOUND·ANIME·GAME) 선택 → 후보의 ▶.
2. 쓸 부분이 시작될 때 **[지금 = 시작]**, 끊을 곳에서 **[지금 = 끝]** → **[구간 재생]** 으로 확인. 주황 글씨는 `비고` 의 자르는 기준(예: 브랜드명 직전에서 끊기).
3. **[✅ 이 영상 채택]** → 다음 행으로. 맞는 게 없으면 [❌ 후보 없음], 직접 찾은 영상은 "다른 영상" 칸에 URL 을 넣고 [불러오기].
4. 결과는 **그 브라우저에 자동 저장**(PC 마다 따로 — 한 기기에서 끝내는 게 편하다). 다 되면 **[결과 TSV 보기]** → 복사 → Claude 에게.

## 파일
| 파일 | 뜻 |
|---|---|
| `index.html` | 검수 화면 |
| `data.js` | 화면이 읽는 데이터 — `build_review.py` 가 만든다 |
| `cand-sound.tsv`·`cand-anime.tsv`·`cand-game.tsv` | 후보 원본(`line` = 문제 TSV 줄 번호, `confidence` 상·중·하, `note` 확인할 점) |
| `picks.tsv` | 듣고 고른 기록(채택·제외). **`line` 은 고른 당시 번호** — SOUND 는 10-13 정리 때 4행(무릎팍·해투·자일리톨·콘푸로스트), ANIME 는 1행(드래곤볼 Z, 16번)을 지워 그 뒤 번호가 당겨졌다(`cand-*.tsv` 는 새 번호로 맞춤) |
| `apply_pick.py` · `add_cand.py` | 채택을 TSV 에 넣기 · 후보 추가(임베드 확인, `data.js` 다시 만듦) |
| `build_review.py` | 후보나 문제 TSV 를 고친 뒤 `python build_review.py` 로 `data.js` 다시 만들기 |
| `yt_search.py` | 후보 찾기 도우미: `python yt_search.py "검색어"`(상위 6개 + 임베드 가능 여부) · `python yt_search.py --desc 영상ID`(설명·챕터) |

## 후보 찾을 때 나온 확인거리 (요약)
- SOUND: VJ 특공대(단독 시그널 클립 없음) · 해피투게더(쟁반노래방 코너 통영상뿐, 시작점 직접) · 출발 드림팀(유명 BGM 이 다른 방송에도 쓰임) · 무릎팍도사(오프닝이 바로 제목을 부를 가능성) · 환승연애 행에 교체 후보 "우리 결혼했어요" 도.
