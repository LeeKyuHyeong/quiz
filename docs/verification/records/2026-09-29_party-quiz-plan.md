## 1. 요청과 목적
- 사용자가 원한 것: 12-26 15인(남7·여7·MC1) 1박 2일 행사에서 MC 진행 팀전용으로 장르를 넓힌 노래맞추기. 기존 사이트를 건드리지 않을 것, 저작권 문제 없을 것, 게임 진행을 정리할 것. 먼저 소스 분석부터.
- 개발자 확인 결과(결정 사항, 같은 날 v2 반영): ① 기존 노래 풀은 평상시대로, "새 장르"는 노래 옆의 **대분류**(드라마·애니·게임…) ② 소리 + 공식 유튜브 클립 임베드(캡처 이미지는 출처를 적어도 불가) ③ 남 vs 여 2팀, 사전 선호도 설문으로 밸런스 ④ MC 본인 ⑤ 노트북 콘솔 + TV 보드 ⑥ O-025 등록만 ⑨ 대분류 → 중분류(노래는 연도만) → 랜덤 출제 → A or B → 점수 → 이긴 팀이 다음 대분류(MC 재량). v3 추가 결정: ⑦ 선물 C안(승리 팀 인당 1만원 동일 상품 + 진 팀 인당 3천원 간식, 약 10만원, MVP 없음) · 탈락 규칙(정답자가 빠짐, 먼저 전원 빠진 팀 승리)은 **현장 처리, 앱은 A vs B 그대로** · 라운드 수 제한 없음(MC 종료까지) · 대분류 SONG·SCREEN(드라마+영화)·ANIME·GAME(캐릭터 대사)·PERSON(+MISC 후보) · 연도 5년 묶음. v4 확정: MISC 포함(초성·이모지·넌센스·상식·예능 시그널·CM송) · 1초 듣기 안 함 · 몸으로 말해요는 본게임 전 **몸풀기 모드**로 별도 화면(`/admin/party/warmup`, `WARMUP` 제시어) · 중분류: GAME 대사·효과음만, SCREEN 장면만(OST 는 노래에 포함), ANIME·MISC 표대로 · PERSON 힌트 3단계 → 못 맞히면 MC 가 [목소리 재생] · 판정은 먼저 손 든 팀만, 오답 시 상대 팀 답하기 전까지 기회 없음(MC 재량, 앱 강제 없음). **설계 결정 완료**, 세부 기본값은 plan §8. v5: **로컬 인스턴스(노트북) + 사진·캡처 확정** — `party_item.image_path`·IMAGE 제시·이미지 업로드 추가, 운영 배포 없음(`party` 브랜치, main 에 올리면 운영 `validate` 실패), 노래는 운영 `genre`·`song` 덤프를 로컬 적재(plan §2-3), 설문은 대분류 자신감만. v6: 진행 패턴 3종(A 정지형 사진·텍스트 / B 재생형 노래·소리: 외침에 일시정지 → 오답이면 재개·상대 팀 기회 → 둘 다 오답이면 끝까지 재생 / C GAME 만 힌트 3단계), 인물·장면의 힌트·목소리 제거, MISC 를 QUIZ(초성·이모지·넌센스·상식)와 SOUND(예능 시그널·CM송)로 분리, 재생형 [○팀 오답] 보드 표시(점수 무관). v7: 몸풀기를 **스피드퀴즈**로 확정(`party` 브랜치) — 주제 + 팀별 제한 시간(임산부 배려), 출제자 1명·정답자 6명 제시어마다 교대, 시간 종료 시 제시어 멈춤·버튼 잠금, 보드에 정답 수, 승자가 본게임 첫 대분류 선택. 말로/몸으로는 같은 화면의 옵션. 가정: 제시어마다 출제자 교대, 제시어는 TV 에 표시하고 정답자들이 등을 돌림.
- 진행 중 둔 가정: 새 콘텐츠는 `song` 이 아니라 신규 `party_item` 테이블(추가만, 로컬 DB 에만 CREATE — 운영 배포 없음, `party` 브랜치) · 파티 게임 상태는 서버 전체 싱글턴 `PartyGameHolder` + JSON 스냅샷(v7 후속에서 `HttpSession` 안을 폐기), `GameSession` 미생성 · 연도 중분류는 5년 묶음 추천.

## 4. 영향 범위 분석 (계획 단계에서 확인한 것)
- `GameHostController`·`game-host-play.js`·`host/play.html`: MC 진행형 원형. 정답자 100점 고정(문서의 100/70/50 과 불일치).
- `Genre` 는 DB 행, 관리자 추가 가능. `findActiveGenresForGame` 은 RETRO 만 제외 → 새 장르는 Solo Guess·Host·Multi 설정, 장르 챌린지, 랭킹에 즉시 노출.
- `SongRepository` 게임 조회는 `use_yn='Y'`·YouTube ID·`genre.code<>'RETRO'`·`is_popular` 만 필터, 장르 `use_yn` 미확인 → 새 곡은 RANDOM 풀·아티스트·연도 목록에 포함.
- `youtube-player.js` `createPlayer` 가 `height:'0', width:'0'` 고정 → 파티 콘솔은 크기 옵션 필요.
- `SecurityConfig`: `/admin/**` ADMIN, 나머지 permitAll → 파티 경로를 `/admin/party/**` 에 두면 무변경.
- `home.html` 카드 하드코딩 → 파티 모드는 홈 미노출로 무변경.
- 곡 등록 도구 `tools/song_register_mcp` 가 신규 장르 코드 생성 지원.
