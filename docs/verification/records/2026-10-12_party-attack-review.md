### 수정 A (1회차 심각) — 저장 안 한 "콘솔에만" 으로 시작하면 제시어가 TV 에
- 재현: 스피드 콘솔에서 [콘솔에만] 만 누르고 [설정 저장] 없이 [▶ 시작]. 서버는 저장된 설정(기본 `wordOnBoard=true`)으로 턴을 돌려 보드 응답에 제시어를 싣는데, 콘솔은 저장 안 된 초안을 계속 그려(`if (!dirty)`) "콘솔에만" 이 켜진 것처럼 보이고 턴 중엔 설정이 잠긴다 → 등을 안 돌린 맞히는 팀이 TV 에서 제시어를 본다.
- 수정(`party-speed-console.js`): 초안이 있으면 [시작] 이 "저장하고 시작할까요?" 를 묻고 저장에 성공해야 시작한다(취소·저장 실패면 시작 안 함). 턴 제목에 서버의 실제 설정 "TV 에 제시어 보임/숨김" 을 표시.

### 수정 B (2회차 심각) — 다른 창의 낡은 초안이 "콘솔에만" 을 덮어씀
- 재현: 콘솔 2개(노트북·휴대폰). 노트북에서 제한 시간만 고쳐 초안이 남음(제시어 표시는 옛 값 "보드") → 휴대폰에서 [콘솔에만] 저장 → 노트북 [시작] → 확인. 초안 저장이 `wordOnBoard=true` 를 보내고 서버는 설정 전체를 덮어씀. 폴링이 `version` 은 최신으로 갱신하므로 버전 확인이 낡은 초안을 못 거른다. 수정 A 이전에도 [설정 저장] 버튼으로 같은 일이 났다.
- 수정: 고치기 시작할 때의 서버 설정을 기억(`draftBase`)하고, 저장 직전 서버 설정이 그 사이 바뀌었으면 저장하지 않고 초안을 서버 값으로 되돌린 뒤 "다른 창에서 설정이 바뀌었습니다" 안내. 대기 화면 제목에도 "TV 에 제시어 보임/숨김"(초기화로 보드 표시로 돌아간 것도 시작 전에 보임).
- 3회차 경미 손봄: 바꾼 것 없이 [설정 저장] → "바꾼 설정이 없습니다"(거짓 "다른 창" 안내 대신) · 비교 때 주제 순서 정렬(재시작 뒤 Set 순서가 바뀌어도 거짓 거부 없음).
